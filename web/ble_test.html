使用提示

ios 蓝牙需用 Bluefy 浏览器打开，并全程保持本页在前台——切到后台 BLE 连接会在几十秒内断开。

USB 串口需用电脑版 Chrome / Edge（同样是 https 或 localhost 才能拿到串口权限）。

支持 JPG / PNG / WebP，浏览器本地完成四色转换
X 0 Y 0 在预览上按住拖动可调整位置
黑 白 黄 红 552 × 768 · 四色 2bpp · 竖屏
当前量化使用「理想四色」；下面的色板只用于浏览器预览和校准，不改变四色边界。 四种墨水实际只能混出红→黄暖色带（蓝/青/绿无法叠加出来），所以先按亮度做自动色阶， 再按「色彩」策略把颜色映射进暖色带，最后用真实图像边缘做对比度感知误差扩散， 并对中性灰限制为黑/白，减少白字红边、白脸黄边和黑色线稿串色。
显示色板校准（仅影响预览）
下载校准图 → 用本页上传到屏幕（抖动选“无”）→ 对屏幕拍照 → 取四个色块 RGB → 填回。 这些值只用于浏览器预览，不会改变原图的四色量化。
日历生成
黑 白 黄 红 预览为四色量化结果 · 2bpp
日历是浏览器生成的静态图片，日期变化后需重新生成并上传；设备无 RTC，不会自动翻页。 农历与节日由浏览器内置中国历法换算，横版会顺时针旋转 90° 写入 552×768 帧，需横持设备查看。
